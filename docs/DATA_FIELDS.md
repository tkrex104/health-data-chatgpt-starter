# Data Fields

| Field | 意味 |
|---|---|
| `date` | 記録日。`YYYY-MM-DD`形式。 |
| `weight_kg` | 体重（kg）。 |
| `body_fat_pct` | 体脂肪率（%）。 |
| `muscle_mass_kg` | 筋肉量（kg）。計測機器の表示に合わせて記録。 |
| `sleep_hours` | 睡眠時間（時間）。 |
| `readiness_score` | 自分が使う機器や記録でのコンディション指標。尺度は機器ごとに異なる場合があります。 |
| `steps` | 歩数。 |
| `active_kcal` | 基礎代謝を除く、活動や運動による消費カロリー。機器の定義に従います。 |
| `total_kcal` | 基礎代謝を含む、その日の総消費カロリー。機器の定義に従います。 |
| `intake_kcal` | 食事から摂取したカロリー。 |
| `protein_g` | たんぱく質（g）。 |
| `fat_g` | 脂質（g）。 |
| `carbohydrate_g` | 炭水化物（g）。 |
| `note` | 食事、運動、外出、体調などの任意メモ。 |

空欄の項目があっても構いません。数値の意味や計測条件が変わった場合は、`note` に残すと後から振り返りやすくなります。
